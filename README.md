# VYBE — Coming Soon

Standalone static landing page for https://vybe.monster. No build step, no dependencies,
no backend, no tracking. Separate from the main VYBE application.

- `index.html`, `styles.css` — the page
- `favicon.svg`, `favicon-32.png`, `apple-touch-icon.png`, `og-image.png` — icons and social preview
- `CNAME` — custom domain for GitHub Pages

Local preview: `python3 -m http.server 8080` then open http://localhost:8080
